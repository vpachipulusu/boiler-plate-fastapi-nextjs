# Freejoy Claude Code handoff — quick start

1. Clone your existing template into a new project repository; keep the template reusable. Or create a new branch in a safe checkout.
2. Extract the `design-reference/freejoy/` folder from the handoff ZIP into your project, for example `design-reference/freejoy/`.
3. Start Claude Code at the repository root.
4. Paste all of `FREEJOY_CLAUDE_CODE_MASTER_PROMPT.md` as your initial message.
5. Allow Claude Code to read `.claude/CLAUDE.md`, `fastapi_backend/CLAUDE.md` and the design images. It should implement Phase 1 first and stop for visual review.
6. Review the generated desktop and mobile pages before authorizing backend and newsletter implementation.

All reference offers and visual examples are illustrative. Do not publish them as real deals.
